# Upload Demo Dataset

This is a small synthetic dataset for checking the upload, file-role selection,
quality preview, and activation flow. It does not describe real people or real
social-media activity.

Upload all three CSV files together and assign these roles:

- `users.csv` -> Users
- `relationships.csv` -> Relationships
- `tweets.csv` -> Tweets

All identifiers referenced by relationships and tweets exist in `users.csv`.
The set contains 5 users, 8 directed relationships, and 6 tweets.

In the upload page, use this optional source note:

`Synthetic demo data for upload workflow testing`

After the check finishes, review the file-read, quality, issue, and capability
sections. Activate the preview only if you want to switch the current analysis
session to this temporary dataset.
