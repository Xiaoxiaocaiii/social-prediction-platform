# 社交网络分析数据来源与授权元信息

> 文档用途：定义数据来源、用户资料、推文展示、授权提示和导出元信息边界。
> 适用范围：内置“智库社交网络数据”和当前会话上传数据。
> 字段规则见[数据字段契约](social-network-analysis-data-field-contract.md)；用户可见范围见[当前功能与实现约定](social-network-analysis-current-implementation.md)。

## 1. 数据集身份

### 1.1 页面模块

```text
社交网络分析
```

### 1.2 内置数据集名称

```text
智库社交网络数据
```

### 1.3 数据集描述

```text
智库等机构账号的用户关系与推文互动数据
```

### 1.4 数据内容范围

内置数据集包含三类主要内容：

- 用户账户资料；
- 用户之间的关注关系；
- 当前采集的推文和互动字段。

页面可展示已核对的规模摘要：

```text
用户：626
关注关系：12,963
推文样本：237,840
```

规模数字必须与当前数据集版本、质量报告和统计范围绑定，不作为永久固定文案写死在业务结论中。

## 2. 正式来源说明

所有页面、质量报告、能力说明和导出结果统一使用以下文案：

> 当前数据由项目开发者整理并提供，具体采集来源、时间范围、数据处理方式和授权说明以最终数据说明文档为准。

当前仓库未附带完整的采集来源清单或授权证明材料。因此，产品只说明数据由项目开发者整理提供，不宣称具体来源、采集范围或平台授权已经核验；使用者仍需自行确认数据使用权限与隐私合规要求。

### 2.1 禁止替换的表达

不得使用：

- “学姐提供的数据”；
- “某机构官方数据”，除非后续有正式确认；
- “全网公开数据”，除非后续有正式范围证明；
- “实时社交平台数据”；
- “完整历史数据”；
- “已获得平台授权”，除非后续有明确授权材料；
- 未经确认的采集机构、爬虫来源或授权主体。

### 2.2 来源文案使用位置

必须统一出现在：

- B01 数据集身份区；
- 数据质量报告详情；
- B02 网络总览口径区；
- B05 用户详情资料边界；
- B06 推文详情和导出确认；
- B07 主题结果限制区；
- CSV/JSON/打印摘要导出元信息；
- 用户上传数据集说明区。

## 3. 采集时间和统计范围

### 3.1 已知时间范围

当前内置推文样本已盘点到：

```text
2016-05-03 至 2026-01-21
```

该范围只表示当前已核对推文样本的时间范围，不表示平台完整历史记录范围。

### 3.2 页面标准文案

数据集时间范围可显示为：

```text
当前采集推文样本时间范围：2016-05-03 至 2026-01-21
```

必须同时显示：

- 数据集名称；
- 数据集版本；
- 当前筛选范围；
- 推文样本量；
- 时间字段解析状态；
- 数据质量提示。

### 3.3 时间范围未知时

如果上传数据没有有效时间字段，显示：

```text
时间范围：未提供有效时间字段
```

如果只有部分记录可以解析，显示：

```text
时间范围：部分记录可解析
说明：未解析记录不参与时间分布统计，但保留在原始样本中。
```

禁止：

- 用上传时间代替推文发布时间；
- 用文件名推断时间；
- 用默认日期补齐空值；
- 将部分时间样本描述为完整时间范围。

## 4. 数据集类型和生命周期

### 4.1 内置数据集

标识：

```text
数据集类型：内置数据集
数据集名称：智库社交网络数据
```

规则：

- 作为平台默认数据；
- 可以被重复加载和复用；
- 结果必须绑定数据集版本；
- 不因为用户上传失败而被覆盖；
- 不修改原始 `all_csv/` 和 `csv/` 文件。

### 4.2 用户上传数据集

标识：

```text
数据集类型：当前分析会话上传
```

规则：

- 只在当前分析会话使用；
- 上传数据不作为永久数据集保存；
- 不默认写入长期数据集目录；
- 不覆盖内置“智库社交网络数据”；
- 会话结束后不承诺保留；
- 导出结果可保留用户主动下载的文件，但平台不将其作为永久数据集；
- 上传数据的来源由用户负责确认。

页面提示：

```text
用户上传数据仅用于当前分析会话，不会注册为永久数据集。
```

### 4.3 用户上传来源文案

用户上传数据不自动复用内置数据集来源文案作为其真实来源声明。页面显示：

```text
数据来源：用户上传
来源说明：请确认该文件的采集来源、时间范围、处理方式和授权边界。
```

如果用户没有提供来源说明，显示：

```text
来源说明：用户未提供
```

不得根据文件名、目录名或字段值推断授权结论。

## 5. 用户资料展示边界

### 5.1 允许展示

在已确认的答辩和研究展示范围内，可以展示：

- 完整用户名；
- 显示名称；
- 简介；
- 账号 ID；
- 粉丝数；
- 关注数；
- 账号创建时间；
- 注册地；
- 当前网络位置指标；
- 当前采集推文样本摘要。

### 5.2 展示前提

用户资料展示必须同时带：

- 数据集名称；
- 数据集版本；
- 字段来源；
- 当前资料采集状态；
- 数据时间或范围；
- 缺失字段提示；
- 原始字段和计算指标的区分。

### 5.3 缺失资料

如果用户资料未采集：

```text
资料未采集
```

只显示可确认的：

- 账号 ID；
- 关系位置；
- 外部节点状态；
- 数据关联状态。

不得根据推文、用户名片段或关系邻居补写：

- 用户名；
- 显示名称；
- 简介；
- 粉丝数；
- 关注数；
- 账号身份。

### 5.4 原始账户字段边界

用户资料中的：

```text
推文总数
```

必须显示为：

```text
用户资料中的推文总数
```

当前采集推文统计必须显示为：

```text
当前采集推文样本
```

二者不得合并，不得把采集样本解释为账号完整历史推文数。

## 6. 推文原文展示边界

### 6.1 允许展示

允许在用户详情、推文排行、推文详情和答辩展示中显示：

- 推文 ID；
- 推文原文；
- 发布时间；
- 作者关联状态；
- 点赞数；
- 评论数；
- 转发数；
- 书签字段状态；
- 数据集版本；
- 当前统计范围。

### 6.2 原文展示说明

推文原文区域必须附：

```text
原文来自当前采集推文样本，不代表账号完整历史推文。
```

并显示：

- 推文来源；
- 采集时间或发布时间；
- 是否已去重；
- 是否存在作者关联；
- 当前展示是否受筛选条件限制。

### 6.3 未归属来源

`Arab_API` 等无法关联到用户 ID 的来源：

- 可以出现在全局推文结果；
- 必须标记“未归属来源”；
- 不进入默认用户排行；
- 不进入默认用户详情；
- 不生成虚构作者资料；
- 不进入主题相关用户网络；
- 仍然可以计入质量报告中的未归属推文数量。

### 6.4 原文和文本分析

- 原文不得被清洗文本覆盖；
- 关键词和 TF-IDF 使用独立分析文本；
- 文本清洗规则和版本单独记录；
- 关键词不代表用户立场；
- 文本匹配不代表传播路径或因果关系。

## 7. 互动字段展示边界

点赞、评论、转发必须分别显示：

```text
点赞总量 / 平均点赞 / 有效样本
评论总量 / 平均评论 / 有效样本
转发总量 / 平均转发 / 有效样本
```

禁止：

- 合成“综合互动量”；
- 合成“互动影响力”；
- 把静态粉丝数与互动量相加；
- 把互动量解释为社会影响力；
- 把转发数量解释为传播因果。

书签字段：

```text
当前数据暂无有效书签差异
状态：disabled
```

空值与零值：

- 空值：未采集/无法关联；
- `0`：明确采集到的零值；
- 不允许把空值批量转换成 0。

## 8. 数据质量和展示提示

### 8.1 必须公开的质量信息

页面和报告可以展示：

- 重复推文数量；
- 内容冲突数量；
- 外部节点数量；
- 未归属来源推文数量；
- 作者关联率；
- 推文时间解析率；
- 互动字段空值数量；
- 书签字段全零状态；
- 资料缺失用户数量；
- 当前数据集文件组成。

### 8.2 质量提示强度

| 情况 | 页面状态 | 推荐文案 |
| --- | --- | --- |
| 数据完整 | healthy/available | 当前数据可用于主要分析 |
| 有重复或外部节点 | available_with_warnings | 部分记录存在质量提示，结果仍可使用 |
| 关键文件或字段缺失 | partial | 部分分析能力受限 |
| 无法读取或无法关联 | unavailable | 当前数据不足以支持该分析 |
| 书签全为 0 | disabled | 暂无有效书签数据 |

### 8.3 质量提示边界

- 质量报告识别、汇总和解释问题；
- 质量报告不直接修改原始数据；
- 质量提示不被写成用户行为结论；
- 质量警告不被隐藏；
- 质量警告不阻塞仍可用的分析能力。

## 9. 导出元信息

### 9.1 所有导出必须包含

- 数据集名称；
- 数据集类型；
- 数据集版本；
- 来源说明；
- 导出时间；
- 当前筛选范围；
- 统计样本量；
- 去重规则；
- 规范化版本；
- 指标版本；
- 文本处理版本，如适用；
- 缺失、外部节点和未归属来源提示；
- 结果边界说明。

### 9.2 推文原文导出提示

在用户导出包含推文原文的结果前，显示：

```text
即将导出当前筛选范围内的推文原文及互动字段。
结果仅代表当前数据集和当前采集样本，请确认其使用范围、授权边界和隐私要求。
```

导出文件中附加：

```text
原文说明：推文内容来自当前采集样本，不代表账号完整历史推文。
来源说明：用户未提供
```

### 9.3 用户上传导出提示

用户上传数据导出时使用：

```text
数据来源：用户上传
说明：平台未核验该文件的采集来源、时间范围、处理方式和授权边界。
```

不得自动把用户上传文件标注为项目内置数据。

### 9.4 导出范围

导出必须明确属于：

```text
当前筛选结果
```

不得使用：

- 全量历史数据；
- 完整账号数据；
- 全网数据；
- 官方完整数据。
