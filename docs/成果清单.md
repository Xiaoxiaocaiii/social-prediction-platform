# 项目成果清单

## 项目名称

多模态社交媒体流行度预测与可视化分析平台（可作软件著作权申报名称）

## 一句话简介

基于 SMTPD 数据集（282,481 条真实 YouTube 视频，含封面图、文本与 30 天热度序列）的流行度预测与可视化平台；
页面全部为真实数据，检索/预测采用基线实现，模型可后接入。

## 技术栈

- 后端：Java 17 + Spring Boot 3.2.5 + Maven + SQLite（sqlite-jdbc）
- 前端：静态 HTML/CSS/JS + ECharts 5.5.1（全部本地化，断网可用）
- 数据：Python 脚本构建 SQLite 索引（FTS5 trigram 中文全文检索）
- 测试：JUnit 5 + MockMvc（24 项用例，全部通过）

## 数据资产

| 资产 | 说明 |
|---|---|
| `data/basic_view_pn.csv` | SMTPD 原始数据 608MB（282,481 行、45 列） |
| `data/smtpd.db` | SQLite 索引 1.89GB（15 个分类，FTS5 全文索引） |
| `data/img_yt.zip` | 封面压缩包 9.25GB（301,408 个条目） |
| `data/covers/` | 本地封面 19,732 张（轻量方案，缺失按需从 zip 补提） |

## 接口清单（统一返回 `{code, message, data}`）

| 接口 | 说明 |
|---|---|
| `GET /api/health` | 健康检查 |
| `GET /api/videos` | 分页 / 分类筛选 / 排序 / 搜索（FTS + LIKE 兜底） |
| `GET /api/videos/{id}` | 详情 + 30 天曲线 + 峰值天/衰减率 |
| `GET /api/insights` | 分类热度、Day1-Day30 相关性、平均衰减曲线 |
| `POST /api/compare` | 2~3 个视频曲线对比 |
| `POST /api/predict` | 上传图文 + 30 天基线预测 |
| `GET /covers/{前缀}/{id}.jpg` | 封面（按需提取 / 占位图） |

## 页面（4 个）

1. 上传预测：参考案例 + 30 天预测曲线（明确标注基线预测）
2. 热度排行榜：筛选 / 搜索 / 分页 / 详情弹窗（真实曲线与指标）
3. 数据洞察：分类热度对比、Day1-Day30 相关性散点（r = 0.9296）、平均衰减曲线（整体/分类）
4. 曲线对比：多视频叠加曲线 + 指标表 + 预置示例

## 与申报书对应

| 申报书要点 | 平台落地 |
|---|---|
| 数据集构建 | 数据浏览 + 数据洞察（28 万条真实数据） |
| 时序建模 | 30 天预测 + 衰减/相关性分析 |
| 检索增强 | 参考案例（检索增强基线预测） |
| 生成增强 | 离线模型实验 + 静态成果展示（不放假图） |
| 系统实现 | 平台本身可申报软件著作权 |

## 模型接入点

- 配置：`app.prediction-mode` = `baseline`（默认）/ `remote`
- Python 服务契约：`POST http://127.0.0.1:5001/predict`
  - 入参：`{ "text": "...", "imagePath": "...", "topK": 5 }`
  - 出参：`{ "prediction": [30], "references": [...] }`
- 生成增强：`flax/stable-diffusion-2-1` 离线样例 + 预留 `POST /api/generate` 契约

## 运行方式

```bat
start.bat
```

或 `mvn -s mvn-settings.xml spring-boot:run`，浏览器打开 http://localhost:8080。

测试：`mvn -s mvn-settings.xml test`
