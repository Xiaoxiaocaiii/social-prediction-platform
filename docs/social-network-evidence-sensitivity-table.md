## 核验范围

本表汇总 EA14 对 `think-tank-social-network/v1` 的参数与范围敏感性结果，并结合 EA17 独立核验确认全网基准。快照时间为 `2026-10-29T08:18:23.731938300Z`，总体为 626 个节点、12,963 条有效有向边。完整网络是主分析范围；最大弱连通分量只作范围对照。

EA17 从规范化记录独立重建节点/边并复算结构统计，确认节点/边集合、全量 k-core、PageRank、介数及 EA07/EA12 正式 K=20 对照与生产结果相符。EA17 不独立验证 CSV 解码和规范化规则。

## 结论边界

- 本快照内，移除 85 个孤立节点没有改变最大分量共有节点的五项排名或扩展 Top-K 名单；这是单一静态网络的范围对照，不是跨时间稳定性或外部数据验证。
- 核心层覆盖规模与跨指标集合重合受阈值/K 选择影响。正式展示应同时标出总体、阈值、K 和并列规则，不挑选有利参数。
- PageRank 与介数绝对值依赖分析总体；排名不变不能解释为两个范围下的网络量纲或数值可直接互换。
- 未进行抽样不确定性、bootstrap、显著性检验或因果推断；这些结构指标不证明现实影响力、话语权或传播因果。
