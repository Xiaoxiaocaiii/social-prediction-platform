# 社交网络分析功能边界说明

> 本文说明当前交付能力和数据解释边界。页面运行状态应在目标环境中实际核验；功能范围见[当前实现约定](social-network-analysis-current-implementation.md)。

## 1. 文档目的

本文档用于说明当前社交网络分析模块的主要能力，以及现有数据不能支持的结论。

本文只说明当前能力、数据限制及结论边界。

## 2. 当前数据基础

当前内置数据集包含三类核心数据：

| 数据类型 | 主要内容 | 当前用途 |
|---|---|---|
| 用户数据 | 用户 ID、用户名、显示名称、粉丝数、关注数、推文总数等 | 用户资料和账号属性分析 |
| 关系数据 | 用户之间的关注关系 | 有向网络、入度、出度、PageRank 和社群分析 |
| 推文数据 | 推文内容、发布时间、点赞数、评论数、转发数等 | 文本主题和互动统计 |

当前数据集的基础规模以实际加载结果为准，页面目前显示：

- 用户：626；
- 关注关系候选：12,963；
- 推文样本：237,840。

这里的“用户数”来自合并后的用户信息表，不等同于爬虫阶段的种子账号数或成功采集账号数。若不同来源出现数量差异，应先对账号 ID 和数据版本进行核对。

## 3. 当前已经实现的功能

### 3.1 数据集入口和质量检查

当前系统可以：

- 读取内置用户、关系和推文数据；
- 统计用户、关系和推文数量；
- 识别重复用户 ID；
- 识别重复关系和自环关系；
- 识别重复但字段冲突的推文；
- 检查用户、关系和推文之间的关联情况；
- 对数据集标记为“可用”“部分可用”或“不可用”；
- 展示缺失、冲突、重复和未关联等质量问题。

“部分可用”表示主体数据可以用于分析，但部分记录存在缺失、冲突或无法关联的情况，并不表示整个数据集不可用。

### 3.2 网络整体统计

当前系统可以计算：

- 用户节点数；
- 有效关系数；
- 网络密度；
- 孤立节点数；
- 外部节点数；
- PageRank 计算状态。

这些指标用于描述网络整体结构，不用于直接判断社会影响力或关系亲密程度。

### 3.3 用户关系和重要节点

当前系统可以：

- 查询指定用户；
- 查看一阶或局部关注关系；
- 展示关注关系方向；
- 按入度排序；
- 按出度排序；
- 按 PageRank 排序；
- 按用户资料中的粉丝数、关注数和推文总数排序；
- 查看用户详情、关系和推文摘要。

其中：

- 入度是当前数据集中指向该用户的有效关系数量；
- 出度是当前数据集中该用户指向其他用户的有效关系数量；
- 粉丝数和关注数来自用户资料字段；
- 入度、出度和账号资料字段的统计范围可能不同；
- PageRank 表示网络结构中的相对重要位置，不等于粉丝数或综合影响力。

### 3.4 推文互动分析

当前系统可以：

- 统计点赞、评论和转发数量；
- 计算总量、平均值、中位数和有效样本数；
- 统计零值和缺失值；
- 按推文展示互动排行；
- 按用户聚合互动结果；
- 展示互动数据的时间分布。

这些结果描述的是当前采集样本中的互动数量，不代表账号完整历史数据，也不代表内容传播的完整过程。

### 3.5 文本主题分析

当前系统可以：

- 对推文文本进行规范化；
- 进行关键词匹配；
- 计算词频和文档频率；
- 计算 TF-IDF；
- 回溯匹配关键词对应的推文；
- 展示主题相关用户；
- 将主题相关用户与真实关注关系进行联动。

主题分析用于说明“哪些文本内容与当前查询相关”，不用于判断用户立场、传播因果或社会影响力。

### 3.6 结果导出

当前系统支持将分析结果导出为：

- JSON；
- CSV；
- 可打印摘要。

## 4. 当前功能状态

当前页面包括数据入口与质量检查、网络结构、用户关系、节点排行、用户详情、互动分析和主题分析，也包括全局关系图与团体/社群分析。完整页面范围和本地演示步骤见 [README](../README.md) 与[项目验收与演示说明](验收与演示说明.md)。

- 数据入口支持内置数据和当前会话上传；上传数据先经过服务端预览，再由用户确认使用。
- 网络结构与用户关系功能描述当前数据中的关注关系，并提供局部关系查看。
- 节点排行和用户详情分别展示网络指标与账户资料，不把它们合并成未经验证的综合影响力结论。
- 互动分析使用采集到的推文样本及点赞、评论、转发等聚合字段。
- 主题分析检索推文文本，并可关联作者和真实关注关系。
- 页面提供 JSON、CSV 或可打印摘要等导出入口；具体导出范围由相应模块决定。
- 全局关系图、Louvain 社群、Clique 团体及跨社群连接候选均可用于当前数据分析；这些结果不代表传播路径、现实影响力或因果关系。
- 上传数据可在临时会话中运行 Louvain/Clique，并查看图、成员/团体证据、跨社群候选和相应导出；会话关闭、过期或服务重启后失效。

## 5. 现有数据的客观限制

以下限制来自当前数据字段和时间范围。

### 5.1 不能还原具体互动双方

要还原“谁点赞、评论或转发了谁”，数据需要包含：

- 互动类型；
- 互动发起者 ID；
- 被互动对象 ID；
- 对应推文 ID；
- 互动时间。

当前聚合的点赞数、评论数和转发数无法还原具体互动双方。

### 5.2 不能还原传播路径

传播路径需要：

- 转发链路；
- 回复链路；
- 引用关系；
- 传播时间；
- 原始推文与衍生推文的对应关系。

缺少这些字段时，互动数量不能被解释为真实传播路线。

### 5.3 不能据单一快照说明网络演化

网络变化分析需要多个时间点的数据快照，例如：

- 不同日期的用户关系；
- 新增关注关系；
- 取消关注关系；
- 用户活跃变化；
- 社群合并或分裂过程。

当前单一版本的关系数据只能用于描述该数据版本中的结构，不能据此可靠描述网络演化。

### 5.4 不能验证未来关系预测

验证未来关系预测至少需要：

- 历史关系变化；
- 用户互动记录；
- 多时间点网络；
- 用户属性和行为特征。

只有静态关系网络时，不能验证预测准确率，也不能把算法输出当成可靠预测。

### 5.5 不能据此得出因果结论

判断用户行为之间的影响关系需要：

- 行为发生时间；
- 关系建立时间；
- 内容曝光或互动记录；
- 干预前后的行为变化；
- 对照组或实验数据。

仅凭关注关系、互动聚合数或静态样本，不能得出“某个用户导致了另一个用户行为变化”的因果结论。

### 5.6 指标和群体结果的解释边界

- 粉丝数和关注数来自账号资料字段；
- 入度反映当前数据中记录到的被关注关系；
- PageRank 描述当前网络中的结构位置；
- 互动量来自已采集推文样本中的聚合数据。

这些指标的统计范围不同，不能直接互换或合并成未经验证的“真实社会影响力”分数。Louvain 社群和跨社群连接候选只描述当前规范化关系网络及对应算法结果；它们不识别现实群体，也不表示传播控制力。交付或演示时应按 README 所列步骤核对环境和数据。

- 数据中的推文和关系仅代表已采集范围，不代表账号完整历史。
- 缺失值、无法关联的记录或样本覆盖不足时，结论应限定在实际纳入分析的数据范围内。

## 6. 文档使用方式

本文记录当前数据与分析结论的边界。页面和接口能力以当前代码为准；若实现变化，应同步更新本文及相关契约。
