# 演示脚本与故障应对

## 演示流程（约 5 分钟）

1. **开场（30 秒）**：默认打开「趋势发现」首页——大标题、搜索框、今日热点 Top 5（真实数据 + 涨跌标识）；一句话介绍：基于 282,481 条真实 YouTube 数据（SMTPD）的流行度预测与可视化平台。
2. **搜索联动（40 秒）**：输入「三毛水果艺术」回车（或点示例词），自动跳转到上传预测并出结果；展示参考案例、30 天预测曲线、KPI 行（峰值天 / 预测 Day30 / 案例数）与全站平均对照虚线；说明「基线预测 = 参考案例真实曲线平均，模型接入后替换」。
3. **热度排行榜（1 分钟）**：展示 KPI 指标行、排名序号与涨跌角标；搜索「火锅」（约 167 条）→ 翻页 → 点开一个视频看真实 30 天曲线、峰值天、衰减率。
4. **数据洞察（1 分钟）**：指出 KPI 行 r = 0.9296，说明「早期热度决定最终热度」；衰减曲线说明热度随时间衰减的整体规律；结论标题直击要点。
5. **曲线对比（1 分钟）**：点「示例：热门 vs 冷门」，叠加两条真实曲线，表格内迷你趋势线直观对比。
6. **主题与动效（30 秒）**：点击右上角图标切换浅色/深色模式，展示图表实时重绘；可顺带展示预加载、图表入场动画。
7. **收尾（30 秒）**：架构一句话——Java 网关 + SQLite 索引 + 本地化前端；模型接入点已预留（`app.prediction-mode=remote`）。

## 常见故障应对

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 双击 start.bat 窗口闪退 / 页面打不开 | JDK 或 Maven 未安装、未配置 | 运行 `java -version`、`mvn -version` 确认；安装 JDK 17 + Maven 3.9 |
| 端口 8080 被占用 | 其他程序占用端口 | `netstat -ano \| findstr 8080` 找到 PID 结束进程，或修改 `application.yml` 的 `server.port` |
| 页面能开但接口报错 | 数据文件缺失 | 确认 `data/smtpd.db` 存在；缺失时运行 `python scripts/build_index.py` 重建 |
| 预测返回「未找到参考案例」 | 文案在数据中无匹配 | 属正常兜底（改用全库平均曲线），换备用文案即可 |
| 数据洞察首次加载较慢 | 全量 28 万条统计 | 约 3~5 秒属正常，正式演示前先打开一次预热 |
| 封面显示占位图 | 该视频封面未提取或缺失 | 自动从 zip 按需补提，或显示占位图，不影响演示 |
| 控制台中文乱码 | 代码页问题 | 运行 `chcp 65001` 切换 UTF-8 |

## 断网说明

页面、样式、ECharts 等全部本地化，无外网依赖；数据请求走 localhost。唯一的外部链接是详情页的「查看原视频」（跳转 YouTube），断网时点击无响应属预期。
