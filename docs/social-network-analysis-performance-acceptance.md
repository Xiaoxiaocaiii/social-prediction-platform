## 4. 缓存复用和失效

- 应用重启后的首次数据集请求约 33ms；
- 同一数据集、同一版本的第二次请求约 3ms；
- 网络总览和 PageRank 排行在快照复用后保持 1–2ms；
- 快照键使用 `datasetId|datasetVersion`，当前版本为 `think-tank-social-network|v1`；
- 当前服务没有在线修改内置数据集版本的管理入口，因此未通过 HTTP 模拟版本升级；版本变化时会因缓存键变化重新构建快照；
- 缓存仅保存内存快照，不回写 `all_csv/` 或 `csv/`，预测模块不共用该缓存。

## 5. 2026-10-05 内存观测与后续优化方向

服务进程在完成真实数据加载、互动分析、主题查询和导出后：

- 工作集约 `2,236MB`；
- Private Memory 约 `2,602MB`。

当日结论（历史记录）：

- 在本地真实数据验收环境中，功能响应时间全部达到规划目标；
- 内存占用是当前主要风险，原因是用户、关系、推文、网络、互动和文本分析结果同时保留在内存快照中；
- 当前采用快照复用避免每次请求重复读取 237,840 条推文；
- 后续若数据规模继续增长，应优先采用分区文本索引、按需导出、局部结果缓存和异步大结果生成；
- 在内存压力场景下，保留 `limited` 状态和 Top-K/深度限制，不以减少真实样本或改变统计口径换取速度。
