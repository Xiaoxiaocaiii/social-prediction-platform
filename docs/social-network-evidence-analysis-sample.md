# 内置智库账号网络（2026-10-29 快照）：连接结构与核心层证据

> 本文数字描述其标注的内置数据快照，不代表当前服务状态或当前本机数据文件。原始 CSV 位于本机 `all_csv/merged_dataset/`，不随源码交付。

## 研究问题

当前内置快照中的账号关系是否普遍连通，还是主要由一个连通部分和若干孤立账号构成？k-core 分布能否支持把账号划成明确的“核心”和“边缘”两类？

本文是基于当前数据快照的方法验收样例，不是对参考报告的复现。全文中的“关系”指数据中的关注关系，不表示内容互动、信息传播或现实影响。

## 数据与方法

分析对象为 `think-tank-social-network` 的 `v1` 快照，计算时间 `2026-10-29T08:18:23.731938300Z`。总体含 626 个资料账号和 12,963 条有效、去重且排除自环的有向关注关系；当前网络节点均为资料账号。

节点资料和关系记录来自本机 `all_csv/merged_dataset/all_user_info.csv` 与 `all_csv/merged_dataset/all_following_list.csv`。节点 ID 是证据追溯主键。连通分量按弱连通计算，忽略边方向；k-core 使用无向、无权简单投影，双向关系合并为一条无向边。全网 626 个节点均保留在分母中，包括孤立节点。累计 core `core>=k` 表示达到该阈值的节点数，不等同于精确 shell `core=k`。

## 结果

| 证据问题 | 观测值 | 可支持的陈述 |
| --- | --- | --- |
| 全网是否均匀连通？ | 626 个节点分为 86 个弱连通分量；最大分量有 541 个节点，占 `86.42%`；另有 85 个孤立节点，占 `13.58%`。全部 12,963 条边都在最大分量内。 | 当前快照呈现一个包含大部分节点和全部关系边的主要连通部分，同时存在一批没有关系边的资料账号。 |
| 核心层规模如何随阈值变化？ | `core>=0/1/10/20/30/39` 分别有 `626/541/407/299/164/93` 个节点；最高 core number 为 39，精确 `core=39` 有 93 个节点。 | 所称“核心规模”取决于阈值。数据支持报告完整层级和累计数量，不支持把某个未经论证的切点当作自然的核心/边缘分界。 |
| 指标是否提供相同的排序证据？ | k-core 与入度、出度、PageRank、归一化介数的 Spearman 分别为 `0.8116`、`0.9242`、`0.7846`、`0.8975`；每对有效样本 `n=626`，并列按平均秩处理。 | 这些指标在本快照中的排序呈正向关联，但关联不表示它们等价；k-core/介数描述无向投影，有向度数/PageRank 描述关注方向。 |

## 解释与边界

本快照显示关系边都位于同一个最大弱连通分量，但仍有 85 个孤立资料账号。两个节点例子说明，账号在无向核心层中的位置与其关注方向不是同一个问题：Heritage 的出度为 0，仍处于最高 k-shell；`niwcrso` 在当前记录中没有入边或出边。它们是结构证据，不代表账号的实际活动、组织地位或社会影响力。

k-core 数量随阈值从 626 变化到 93，且最高 shell 本身有 93 个并列节点。因此不采用单一 core 阈值给账号贴“核心/边缘”标签。k-core 和中心性相关系数只描述当前快照中的排序关联，不说明因果，也不构成综合重要度分数。

本分析只覆盖当前整理的静态 `v1` 数据。关系表中的缺边不能证明现实中不存在关系；单一快照无法回答关系何时建立、是否持续或账号是否影响信息传播。这里未做抽样不确定性、显著性检验或外部数据验证，也不按国家、地区或机构类别分组。核心层阈值、Top-K 并列和最大分量范围的补充对照见[敏感性表](social-network-evidence-sensitivity-table.md)。
