# 社交网络分析网络指标与 PageRank 参数契约

> 文档用途：定义当前网络指标、PageRank 参数、排序和边界情况。
> 适用范围：内置及上传数据支持的网络分析接口。
> 相关契约：
>
> - [规范化与数据质量规则](social-network-analysis-normalization-quality-rules.md)
> - [数据字段契约](social-network-analysis-data-field-contract.md)
>
> 页面功能和完整网络/画布范围的区分见[当前功能与实现约定](social-network-analysis-current-implementation.md)。

## 1. 计算对象

网络计算使用规范化后的分析层关系：

```text
G = (V, E)
```

其中：

- `V`：规范化用户节点和关系中出现的外部节点；
- `E`：唯一、有效、方向明确、排除自环后的有向关系边；
- 节点 ID：字符串；
- 边方向：`source_user_id → target_user_id`；
- 边权重：当前不使用，所有有效边权重相同。

### 1.1 纳入节点

当关系数据可用时：

- users 中通过规范化校验的用户节点纳入；
- 关系端点中出现但 users 缺失的节点作为外部节点纳入；
- 没有任何边的有效用户仍可作为孤立节点纳入；
- 外部节点可以参与结构计算；
- 外部节点在排行和图表中必须标记“资料未采集”。

### 1.2 纳入边

只有以下边进入分析图：

- source 和 target 均为有效字符串 ID；
- 关系方向明确；
- 关系不是自环；
- 关系已按端点对去重；
- 关系通过当前规范化校验。

以下记录不进入分析图，但必须保留在原始层和质量报告：

- source 或 target 缺失；
- source 或 target 类型非法；
- 自环；
- 重复边的重复副本；
- 无法解析的聚合关系行。

## 2. 网络规模指标

### 2.1 节点数

```text
node_count = |V|
```

页面必须区分：

```text
有效资料用户数
外部节点数
分析网络节点数
孤立节点数
```

不得只显示一个“用户数”覆盖全部口径。

### 2.2 边数

```text
edge_count = |E|
```

`edge_count` 是去重、排除自环和非法边后的分析边数。

同时保留质量字段：

```text
raw_relationship_count
duplicate_relationship_count
self_loop_count
invalid_relationship_count
```

### 2.3 网络范围

每个网络结果必须携带：

```text
dataset_id
dataset_version
normalization_version
metric_version
node_count
edge_count
include_external_nodes
exclude_self_loops
scope
calculated_at
```

## 3. 入度

### 3.1 定义

对于节点 `v`：

```text
in_degree(v) = |{(u, v) ∈ E}|
```

含义：

> 当前规范化关注关系范围内，指向该节点的唯一有效关注边数量。

在当前方向约定中：

```text
u → v
```

表示 `u` 关注 `v`，因此 `v` 的入度是收到的关注关系数。

### 3.2 计算规则

- 只统计唯一有效边；
- 不按重复边次数累加；
- 不包含自环；
- 外部节点可以有入度；
- 资料缺失不影响结构入度；
- 空关系图中入度为 0，但页面必须显示当前没有有效关系；
- 入度 0 是明确结构结果，不是缺失值。

### 3.3 展示规则

页面显示：

```text
入度：128
统计范围：规范化关系网络
节点状态：已有资料/资料未采集
```

不显示：

```text
社会影响力：128
粉丝增长：128
传播强度：128
```

## 4. 出度

### 4.1 定义

对于节点 `v`：

```text
out_degree(v) = |{(v, w) ∈ E}|
```

含义：

> 当前规范化关注关系范围内，该节点发出的唯一有效关注边数量。

### 4.2 计算规则

- 只统计唯一有效边；
- 不按重复边次数累加；
- 不包含自环；
- 外部节点可以有出度；
- 空关系图中出度为 0；
- 关注数原始账户字段不替代出度；
- 出度不解释为账号真实完整关注数。

### 4.3 原始字段区分

页面必须区分：

```text
出度：当前规范化关系网络中的计算指标
关注数：用户资料中的原始账户字段
```

两者可能不同，不得合并或互相补齐。

## 5. 网络密度

### 5.1 默认公式

对于有向简单图：

```text
density = m / (n × (n - 1))
```

其中：

```text
n = 分析网络节点数
m = 分析网络唯一有效有向边数
```

原因：

- 关系是有向的；
- 不允许自环；
- 同一方向的重复边已经去重；
- 任意两个不同节点最多存在一个方向相同的边。

### 5.2 边界情况

| 情况 | 处理 |
| --- | --- |
| `n > 1` | 按公式计算 |
| `n = 1` | 显示“不可计算”，不显示 0 |
| `n = 0` | 显示“无有效网络节点” |
| `m = 0, n > 1` | 密度为明确 0 |
| 关系含重复边 | 使用去重后的 `m` |
| 关系含自环 | 自环不进入 `m` |

### 5.3 外部节点

默认：

- 外部节点计入 `n`；
- 外部节点之间和指向外部节点的有效边计入 `m`；
- 页面显示外部节点数量；
- 可提供“排除外部节点”的对照范围，但必须作为明确筛选，不得静默切换。

### 5.4 解释边界

网络密度只表示：

> 当前节点范围内实际存在的有向关系边占理论最大有向边数的比例。

不得解释为：

- 关系亲密程度；
- 群体凝聚力的直接证明；
- 社会联系强度；
- 传播效率；
- 因果关系。

## 6. 孤立节点

### 6.1 定义

节点 `v` 满足：

```text
in_degree(v) + out_degree(v) = 0
```

则标记为孤立节点。

### 6.2 处理

- 节点仍计入 `node_count`；
- 节点计入孤立节点数量；
- 不绘制虚假边；
- PageRank 作为悬挂节点处理；
- 页面使用“孤立节点”而非“无效用户”；
- 外部节点如果没有有效边，不应被凭空创建为孤立节点，除非它实际进入规范化节点集合。

## 7. PageRank 定义

### 7.1 定位

PageRank 是基于有向关注关系网络的结构位置指标，用于描述节点在当前网络结构中的相对位置。

页面统一说明：

> PageRank 描述网络结构中的位置，不等同于社会影响力。

### 7.2 计算图

PageRank 使用：

- 唯一有效有向边；
- 排除自环；
- 包含外部节点；
- 包含孤立节点；
- 无权边；
- 不使用粉丝数、互动量或推文数作为权重；
- 不使用文本主题作为权重；
- 不使用个性化用户偏好；
- 不使用时间衰减。

### 7.3 迭代公式

设：

```text
n = |V|
d = 0.85
PR_t(v) = 第 t 次迭代时节点 v 的 PageRank
```

初始值：

```text
PR_0(v) = 1 / n
```

每次迭代：

```text
PR_(t+1)(v)
  = (1 - d) / n
  + d × (
      Σ [PR_t(u) / out_degree(u)] for u ∈ In(v), out_degree(u) > 0
      + dangling_mass_t / n
    )
```

其中：

```text
dangling_mass_t
  = Σ PR_t(u) for all u where out_degree(u) = 0
```

悬挂节点的 PageRank 质量在每轮平均分配给全部节点。

### 7.4 固定参数

| 参数 | 固定值 | 说明 |
| --- | --- | --- |
| `damping_factor` | `0.85` | 阻尼系数 |
| `initialization` | `1/n` | 均匀初始化 |
| `edge_weight` | `unweighted` | 所有有效边权重相同 |
| `dangling_node` | `uniform_redistribution` | 悬挂质量均匀分配 |
| `personalization` | `none` | 无个性化向量 |
| `time_decay` | `none` | 无时间衰减 |
| `self_loop` | `excluded` | 自环不进入计算图 |
| `external_node` | `included` | 外部节点进入计算图 |
| `tolerance` | `1e-8` | L1 差异收敛阈值 |
| `max_iterations` | `100` | 最大迭代次数 |

### 7.5 收敛条件

每轮计算：

```text
delta = Σ |PR_(t+1)(v) - PR_t(v)|
```

当：

```text
delta < 1e-8
```

认为收敛。

如果达到 100 次仍未收敛：

- 结果状态标记为 `failed` 或 `unavailable`；
- 不返回未收敛结果作为正常 PageRank；
- 保留其他可用网络指标；
- 质量报告记录迭代次数和失败原因；
- 页面提供重试或查看入度/出度排行的替代入口。

### 7.6 结果校验

收敛后应检查：

```text
Σ PR(v) ≈ 1
```

允许浮点误差，但必须记录：

- 迭代次数；
- 最终 delta；
- 总和偏差；
- 参数版本；
- 节点和边范围。

## 8. PageRank 展示规则

### 8.1 数值

- 原始计算值保留；
- 页面可按统一精度显示；
- 排名使用原始精度，不使用四舍五入后的显示值；
- 相同原始值按照并列规则处理；
- 排名下一名按实际排序位置编号；
- ID 相同指标时使用字符串 ID 作为稳定次级排序；
- 外部节点显示“资料未采集”。

### 8.2 排名

PageRank 排名表至少包含：

```text
名次
节点 ID
显示名称（如有）
PageRank 原始值
节点状态
样本/范围
指标版本
```

不包含：

- 社会影响力；
- 官方影响力；
- 传播能力；
- 现实身份判断。

### 8.3 网络图

网络图节点可以按 PageRank 调整大小，但必须：

- 图例写明“PageRank 结构位置”；
- 显示当前网络范围；
- 显示节点和边数量；
- 标记外部节点；
- 默认展示上限为 100 个节点和 500 条关系；接口单次请求最多允许 1,000 个节点和 15,000 条关系；
- 不将节点大小称为影响力大小。

## 9. 指标版本和元信息

### 9.1 版本命名

当前固定：

```text
metric_version: network-metrics-v2.0
pagerank_version: pagerank-v1.0
```

如果系统只保留一个指标版本字段：

```text
metric_version: network-metrics-v2.0
```

`network-metrics-v2.0` 标识当前节点、关系、密度和网络结构指标的计算口径；公式和边界以本契约对应章节及当前实现为准。PageRank 使用 `pagerank-v1.0`，实现参数随结果元信息返回。

### 9.2 版本变更条件

以下变化必须升级版本：

- 入度或出度定义变化；
- 密度分母变化；
- 网络结构指标集合、公式、计算范围、投影或边界变化；
- 外部节点纳入范围变化；
- 自环处理变化；
- 不可用值的表达规则变化；
- PageRank 阻尼系数变化；
- 收敛阈值变化；
- 最大迭代次数变化；
- 悬挂节点分配变化；
- 是否使用权重变化；
- 是否使用时间衰减变化。

### 9.3 结果元信息

每个网络指标结果必须附带：

```text
dataset_id
dataset_version
normalization_version
metric_version
pagerank_version
node_count
edge_count
external_node_count
isolated_node_count
include_external_nodes
exclude_self_loops
scope
calculated_at
```

## 10. 空数据和异常状态

### 10.1 无关系

如果没有有效关系边：

- `edge_count = 0`；
- 入度、出度均为 0；
- `density = 0`，前提是 `n > 1`；
- 页面显示“当前范围内没有有效关系”；
- 不绘制虚假连线；
- PageRank 可以在节点集合上计算，但必须提示没有有效边；
- 如果没有节点，网络指标状态为 `unavailable`。

### 10.2 单节点

如果 `n = 1`：

- 密度显示“不可计算”；
- 入度和出度按 0 显示；
- PageRank 为 1；
- 页面显示单节点范围；
- 不将密度的不可计算显示为 0。

### 10.3 只有外部节点

- 外部节点参与结构计算；
- 页面显示“资料未采集”；
- B05 资料区不可用；
- B03/B07 保留结构位置；
- B04 用户资料排行不纳入；
- 质量报告显示外部节点占比。

### 10.4 超大网络

- 默认最多展示 100 个节点和 500 条边；单次请求上限为 1,000 个节点和 15,000 条边；
- 指标计算范围和可视化范围分开标注；
- 超限时不静默截断；
- 页面提示当前图为局部或 Top-K 视图；
- 网络图保留缩小范围入口。

## 11. 人工复核样例

### 11.1 三节点有向环

```text
A → B
B → C
C → A
```

预期：

```text
n = 3
m = 3
in_degree(A) = 1
out_degree(A) = 1
density = 3 / (3 × 2) = 0.5
```

PageRank 在对称结构下应接近：

```text
PR(A) = PR(B) = PR(C) ≈ 1/3
```

### 11.2 含外部节点

```text
A → X
B → X
```

其中 `X` 无 users 资料。

预期：

```text
X 计入节点和入度计算
X 标记为外部节点
X 不显示虚构资料
```

### 11.3 含自环和重复边

```text
A → A
A → B
A → B
```

预期：

```text
原始关系记录 = 3
自环数量 = 1
重复关系数量 = 1
分析边 = 1（A → B）
```

### 11.4 孤立节点

```text
V = {A}
E = {}
```

预期：

```text
node_count = 1
edge_count = 0
in_degree(A) = 0
out_degree(A) = 0
density = unavailable
PageRank(A) = 1
isolated_node_count = 1
```
