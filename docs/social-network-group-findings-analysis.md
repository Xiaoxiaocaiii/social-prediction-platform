## 一、数据口径

- 数据集：`think-tank-social-network/v1`；完整规范化网络，626 个账号节点、12,963 条有效有向关注关系。
- 图投影：两个账号之间只要有任一方向的有效关注，就计作一条无向、无权关系；双向关注合并为一条，得到 10,422 条无向关系。
- Clique：规模至少为 3 的极大团。团内每对账号至少存在一个方向的关注，且无法在当前投影中再加入一个与全部团成员相连的账号。不同团可以重叠。
- Louvain：对同一无向网络按当前默认参数划分算法社群；没有连边的 85 个孤立节点单独列为未分配。
- 关注关系描述的是数据快照，不证明互动、合作、信息传播或影响力。一个账号出现在多个团中，也不等于它属于多个现实组织。

## 四、这些社群之间有没有具体联系？

默认 Louvain 结果有 6 个算法社群；541 个账号被分配，85 个孤立节点未分配。10,422 条无向关系中，5,021 条位于同一社群内，5,401 条跨社群。

**发现：**六个社群之间并非彼此隔离。在本次划分下，15 对不同社群之间均有至少一条无向关系。社群对之间的无向关系数量如下：

## 五、结果有什么边界？

1. 本数据没有经过核实的全球南方/北方分类，不能照搬参考报告的南北占比或地理结论。
2. 任一方向关注即连边；“团内两两有关系”不等于每对账号互相关注，更不证明现实协作或组织关系。
3. 当前结果是静态数据快照，不证明信息流、影响力、话语权或因果关系。缺少关注记录也不证明现实中没有联系。
4. Louvain 的分组依赖投影和参数；已有 CL12 记录显示改变分辨率或采用互相关注投影后分组会变化。6 个社群不是唯一正确的现实群体划分。
5. `#4498` 等列表序号和 C003 等标签只用于定位本次结果，不能无条件跨数据版本沿用。
6. 截至本文核对日，普通页面尚未呈现以上完整的问题、结论和证据，真实证据 API 分页及性能尚未验收。后续页面及上传分析验收见本文开头的现状补充；本文自身的原始 CSV 回查不替代该验收记录。
