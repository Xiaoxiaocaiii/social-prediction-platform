# 项目验收与演示说明

本文面向项目验收和本机演示，说明当前交付范围、运行条件、演示步骤及数据解释边界。社交网络分析的当前实现见[功能与实现约定](social-network-analysis-current-implementation.md)；详细字段、接口和算法口径见该文档列出的契约。

## 交付范围

| 模块 | 当前交付能力 |
| --- | --- |
| 流行度预测 | 首页趋势发现、历史案例检索、30 天基线趋势、排行榜、数据洞察和曲线对比 |
| 社交网络基础分析 | 数据质量、网络结构、局部关系、用户详情与排行、互动、主题及结果导出 |
| 全局关系图与社群 | 关系图、范围/截断说明、Louvain 社群筛选、成员和关系证据、Clique 团体分析 |
| 跨社群连接候选 | 独立候选排行、账号详情、来源关系证据、图内定位及 JSON/CSV/可读报告 |
| 上传数据分析 | CSV/JSONL 质量预览和会话激活；会话内网络图、Louvain/Clique、证据、候选、互动和导出 |

本说明描述当前产品能力，不代表每次检出代码后已重新运行测试或完成浏览器核验。实际验收须在目标机器上按本说明运行并检查结果。

## 当前验证方式

在项目根目录执行后端测试：

```powershell
mvn -s mvn-settings.xml test
```

执行前端契约测试：

```powershell
Get-ChildItem scripts -Filter '*.test.js' | ForEach-Object { node $_.FullName }
```

测试通过不替代浏览器业务验收；页面入口可访问也不单独证明完整分析链路正常。

## 运行前准备

需要：

- Windows 桌面环境、JDK 17、Maven 3.9 或更新版本、Microsoft Edge。
- 项目根目录中的 `pom.xml`、`mvn-settings.xml` 和 `start.bat`。
- 预测模块本机数据：`data/smtpd.db`；封面展示还需要 `data/covers/`，缺失封面按项目现有逻辑处理。
- 内置社交网络分析数据：`all_csv/merged_dataset/all_user_info.csv`、`all_csv/merged_dataset/all_following_list.csv` 和 `all_csv/merged_dataset/all_tweets_raw.csv`。

`data/`、`all_csv/` 和 `csv/` 是本机数据资产，不应通过源码交付提交。只克隆源码且没有这些真实数据时，可以运行服务和使用上传演示样例，但不能据此声称内置真实数据分析链路已运行。`test-data/upload-demo/` 是合成样例，只用于演示上传流程，不代表真实社交网络数据或研究结果。

## 本机启动

在 PowerShell 中进入项目根目录后检查版本：

```powershell
java -version
mvn -version
```

构建并运行测试：

```powershell
mvn -s mvn-settings.xml test
```

启动应用：

```powershell
mvn -s mvn-settings.xml spring-boot:run
```

项目默认端口由 `src/main/resources/application.yml` 配置为 `8080`。浏览器访问：

```text
http://localhost:8080/
```

如默认端口已被占用，可在当前 PowerShell 会话中临时设置其他端口后启动：

```powershell
$env:SERVER_PORT = "18198"
mvn -s mvn-settings.xml spring-boot:run
```

该设置只改变本次进程的 Spring Boot 端口，不要求修改源码。演示前以启动日志中的实际端口为准，并用浏览器打开首页确认页面可访问；HTTP 200 只说明页面服务响应，不等于每个分析模块都已通过业务验收。

## 演示路径

1. 打开 `#/`，查看趋势发现首页。
2. 打开 `#/predict`，提交研究文本，查看真实历史案例和 30 天基线趋势。
3. 打开 `#/social-network`，检查内置数据摘要、质量状态和能力说明。
4. 依次查看 `#/social-network/relations`、`#/social-network/network`、`#/social-network/relations/ranking`、`#/social-network/content` 和 `#/social-network/content/topic`。
5. 在团体与社群页面运行/查看 Clique 和 Louvain 结果；在节点排行进入跨社群连接视图，核对关系方向、来源证据和导出报告。
6. 打开 `#/social-network/data/upload`，选择 `test-data/upload-demo/` 下的三个 CSV，并分别指定 users、relationships、tweets 角色。查看质量预览后再激活；检查会话内关系图、社群、候选、证据、互动和导出。
7. 结束上传会话后确认页面不再使用该会话结果。上传结果是临时会话数据，服务重启后失效。

## 解释边界

- 关系表示数据中记录的关注方向，不表示内容传播路径或现实组织关系。
- Louvain 社群和 Clique 团体是不同的结构分析结果；算法标签不代表现实群体身份。
- 跨社群连接结果是可核对的技术候选，不是影响力、关键中介或因果结论。
- 数据来源与授权由上传者负责说明，平台不会自动核验授权。
- 图形展示受节点和关系上限约束；完整范围数据与画布本次展示数据分开说明。
- 不得依据整机可用内存设置分析准入门槛；Worker 进程资源限制与整机内存门槛是不同概念，详见[Worker 资源约束](social-network-worker-resource-contract.md)。
- 项目只支持桌面 Microsoft Edge；移动端、平板端及触摸布局不在交付范围内。
